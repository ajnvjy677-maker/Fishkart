# Fishkart

Fishkart is a simple website built using HTML, CSS, and Bootstrap.

It is a website interface developed by me, with a header, main section, and footer. It includes responsive cards that adapt to different screen sizes.

## Features

- Header, main, and footer layout
- Responsive cards built with Bootstrap
- Clean, simple interface

## Built With

- HTML
- CSS
- Bootstrap
